# Logger-n-Repeater

A simple tool that records your keystrokes and mouse clicks and repeats them at the press of a button. I used it myself many times and I think it is about time to share it.



First of all, it will only work on Windows, not on Linux nor on macOS (can be modified lightly to do so).

1. Now, you'll need to install the newest version of python and add it to PATH, follow the tutorial online for that.
2. Next install all files, i.e. main.py, winmouse.py, and settings file, and put them all in the same directory.
3. Now open a terminal and run "pip install keyboard" and "pip install mouse", those are the libraries necessary for the program to work.
4. Run the main file in your terminal by typing "python main.py" and pressing ENTER, no parameters are needed. Make sure that the terminal is open from the same directory the "main.py" file is located at.
5. The rest of the instructions can be found once the program is running, enjoy :)



P.S. You may change the controls in the settings folder, simply open it in any editor and replace the keybinds.
